🔄 FLUXO DE EXECUÇÃO DETALHADO
════════════════════════════════════════════════════════════════════════════

1. Utilizador: Clica em RPA_Expedicao.exe
   └─ (Sem ver nenhuma janela - --windowed flag)

2. Launcher.py: Inicia
   ├─ Muda para diretório correto
   └─ Chama: atualizar_repositorio()

3. atualizar_repositorio():
   ├─ Verifica: os.path.exists(".git")
   ├─ SIM → Executa: git pull (com CREATE_NO_WINDOW)
   └─ NÃO → Continua normalmente

4. git pull:
   ├─ SEM INTERNET → Erro capturado, continua
   ├─ GIT AUSENTE → FileNotFoundError capturado, continua
   ├─ TIMEOUT → subprocess.TimeoutExpired capturado, continua
   └─ SUCESSO → Código atualizado

5. Launcher.py: Executa app.py
   └─ exec(open("app.py").read())

6. app.py: Inicia
   ├─ Flask app criado
   ├─ Webview iniciado
   └─ Interface RPA aberta

7. Resultado:
   └─ ✅ Interface RPA com código atualizado (ou versão local se falhou)

ARQUIVO: app.py
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ANTES:
  subprocess.run(["git", "pull"], capture_output=True, text=True, timeout=15)

DEPOIS:
  # Windows: sem mostrar janela
  if sys.platform == "win32":
      creation_flags = subprocess.CREATE_NO_WINDOW if hasattr(...) else 0x08000000
  else:
      creation_flags = 0
  
  subprocess.run(
      ["git", "pull"],
      capture_output=True,
      text=True,
      timeout=20,              # Aumentado para 20 segundos
      creationflags=creation_flags,  # Nova: oculta terminal
      cwd=os.getcwd()
  )

IMPACTO:
  ✅ Terminal não aparece no Windows
  ✅ Timeout reduz travamentos
  ✅ Melhor tratamento de erros
