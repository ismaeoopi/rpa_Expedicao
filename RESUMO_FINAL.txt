🔍 O QUE MUDOU EM app.py
═══════════════════════════════════════════════════════════════════════════════

ANTES:
  subprocess.run(["git", "pull"], capture_output=True, text=True, timeout=15)

DEPOIS:
  if sys.platform == "win32":
      creation_flags = subprocess.CREATE_NO_WINDOW if ... else 0x08000000
  else:
      creation_flags = 0
  
  subprocess.run(
      ["git", "pull"],
      capture_output=True,
      text=True,
      timeout=20,
      creationflags=creation_flags,  # ← NOVO: Oculta terminal
      cwd=os.getcwd()
  )

IMPACTO:
  • Terminal não aparece ✅
  • Timeout maior = menos travamentos ✅
  • Melhor compatibilidade com Windows ✅
  • Código 100% compatível para trás ✅

📞 SUPORTE E TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: "compile_launcher.bat não funciona"
SOLUÇÃO:  
  • Execute: pip install pyinstaller
  • Execute: python test_auto_update.py
  • Verifique erros do teste acima

PROBLEMA: "dist\RPA_Expedicao.exe não se cria"
SOLUÇÃO:
  • Verifique se launcher.py, app.py, templates/ existem
  • Execute: python check_config.py
  • Verifique mensagens de erro no cmd

PROBLEMA: "Aplicativo trava ao abrir"
SOLUÇÃO:
  • Aumentar timeout em app.py (timeout=30 ou 60)
  • Seu repositório é muito grande?
  • Rede lenta?

PROBLEMA: "Terminal fica visível"
SOLUÇÃO:
  • Verifique versão do Windows (precisa 7+ ou Server 2008+)
  • Recompile com: compile_launcher.bat
  • Ou execute diretamente: dist\RPA_Expedicao.exe
