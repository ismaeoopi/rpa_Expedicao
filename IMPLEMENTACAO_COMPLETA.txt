❓ DÚVIDAS RÁPIDAS
════════════════════════════════════════════════════════════════════════════════

P: O que significa "launcher.py"?
R: É o novo programa que vai rodar em vez de app.py. Ele faz git pull 
   silenciosamente e depois abre app.py.

P: Por que eu preciso de PyInstaller?
R: Para converter launcher.py em um .exe que pode ser executado sem Python 
   instalado no PC de cada pessoa.

P: O git pull pode danificar meu código?
R: Não! Git pull apenas lê do repositório. O pior que pode acontecer é 
   um conflito (que não há, se as pessoas não modificaram o código localmente).

P: E se eu não quiser auto-update?
R: Pode deixar .git fora do diretório do .exe. Assim o app nunca tenta 
   fazer git pull.

P: Quanto tempo demora a compilação?
R: 2-5 minutos (depende do seu PC).

P: O que devo fazer agora?
R: Leia START_HERE.txt e siga os 3 passos simples.
